Diagram
=======

The Diagram application in CryptPad is an integration of `Draw.io <https://www.drawio.com/>`__.

.. image:: /images/app-diagram-preview.png
   :class: screenshot

Documentation
-------------

Please refer to the `Draw.io documentation <https://www.drawio.com/doc/>`__ for a diagram user-guide.

.. _app_diagram_theme:

Themes
------

Diagram defaults to the **Sketch** theme. Use |cptools palette| **Theme** in the CryptPad toolbar to switch between the three available themes:

- **Sketch** (default): a simplified infinite canvas suited to mind-mapping, sketching, and freehand drawing.
- **Simple**: a compact interface combining elements of Sketch and Classic.
- **Classic**: the full Draw.io interface with menus, toolbar, and shape libraries.

For more information about these themes, please refer to the `Draw.io documentation on editor themes <https://www.drawio.com/docs/manual/editor/appearance/>`__.

Toolbars
--------

CryptPad integrates Draw.io diagrams into the same encrypted collaboration system as the other applications. Draw.io provides its own toolbar alongside CryptPad’s. This results in a double toolbar that can cause confusion:

- The topmost **CryptPad toolbar** is used for |file-o| **File** operations (including import/export, history, properties, etc) as well as |share-alt| **Share**, |unlock-alt| **Access**, and |cptools palette| **Theme**.
- The **Draw.io toolbar** is used for all functionality within the diagram document itself. Its layout depends on the selected :ref:`theme <app_diagram_theme>`.

Import/Export
-------------

CryptPad toolbar
""""""""""""""""

Import and export diagram files.

| |file-o| **File** > |upload| **Import**.
| Supported formats: ``.drawio``

| |file-o| **File** > |download| **Export**.
| Supported formats: ``.drawio``


Draw.io toolbar
"""""""""""""""

Add content inside your diagram document or preview it in an image format.

| **File** > **Import from**.
| Supported formats: ``.drawio``

| **File** > **Export as**.
| Supported formats: ``.png``, ``.jpg``, ``.svg`` & ``.pdf``
