Код / Markdown#

Код / Markdown приложението в CryptPad е интеграция на CodeMirror.

Лента с инструменти#

Инструменти: Покажи/скрии лентата с инструменти на панела за редактиране на текст.

Добави: Добави снимка към документа. Снимката може да бъде избрана от диска или качена. Влезли потребители

Тема: Настрой цветовете на редактора, детайлно под.

Предварителен преглед: Покажи/скрии менюто за предварителен преглед на Markdown.

Тема#

Цвят от автора: Оцветете текста, написан от разчните потребители, с цвета на техния курсор (избран в потребителски настройки). Когато е активен:

  • Скрии цветовете на автора за да изключите показването на цветовете в този прозорец, те могат да бъдат включени отново и остават активни за другите потребители.

  • Цвят от автора > Почисти и деактивираи за да изключите цветовете за всички потребители и да изтрияте всички данни.

Тема: Цветова схема, използвана в панела за редактиране на код.

Език: Използва се за подчертаване на синтаксиса.

Импортиране/Експортиране#

Файл > Импортиране.
Поддържани формати: Всички файлове с обикновен текст, разширението на файла бива използван да определи езика.
Файл > Експортирай.
Поддържани формати: .md, за името на експортирания файл може да се въведе всяко друго разширение.

Markdown#

The Code application is particularly suited for writing documents in Markdown: a lightweight syntax that offers basic formatting while remaining readable. Markdown is readily converted to other formats such as HTML.

За примери на синтаксис на Markdown в CryptPad моля вижте:

Markdown Guide: Basic Syntax

Допълнително към обикновения синтаксис на Markdown, следните функционалности са налични:

  • [TOC] Добавя таблица със съдържание.

  • Списък със задачи

    • - [ ] task for a task to do: task.

    • - [x] task for a completed task: task.

As well as the following extensions:

  • Диаграми с Mermaid.

  • Мисловни карти с Markmap.

  • Математически уравнения с Mathjax.

To use an extension, name it as syntax for a Markdown code block, for example:

``` mermaid
   <!-- your mermaid code -->
```

За детайлни примери на използваните разширения, моля вижте:

Markdown Guide: Extensions

Снимки#

Markdown syntax to include remote images such as ![description](https://site.com/image.jpg) is blocked by CryptPad for security reasons.

Logged in users

За да добавите снимки от CryptDrive-a или да качите нови, използвайте менюто Добави в лентата с инструменти.

Вижте Remote Content за повече детайли.

Ефект на осветяване#

За да разгледате всички изображения и диаграми в документа, използвайки цялата ширина на прозореца:

  1. Двойно кликане върху снимка или диаграма в предварителен преглед на Markdown.

  2. Навигирайте чрез стрелките на клавиатурата.

  3. Затворете ефекта на осветяване чрез или Esc.
