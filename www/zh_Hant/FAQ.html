常見問題#

常見問題與排除#

若 CryptPad 運作不如預期，可先嘗試以下幾項常見做法。多數情況與瀏覽器及擴充功能有關，可能干擾 CryptPad 的安全機制或關閉瀏覽器基本功能。

  1. 查看下方擴充功能清單，若有安裝請先停用

  2. 嘗試使用瀏覽器的隱私視窗，或停用所有擴充功能後再試

  3. 關閉您可能使用的任何虛擬私人網路 (VPN) 與/或自訂 DNS 過濾服務 (NextDNS、AdGuard DNS...)

  4. 嘗試改用其他瀏覽器。建議使用最新版的 Firefox 或 Chromium

  5. 若問題仍存在，請透過本站的 技術支援 聯絡我們

我忘記密碼了#

CryptPad 站台的管理員無法復原或重設使用者密碼。這也確保他們無法存取任何使用者資料（例如文件內容）。

若您仍登入在已忘記密碼的帳號，可依下列步驟將所有文件轉移到新帳號：

  1. 在仍登入遺失密碼的帳號時，前往：使用者選單**（右上角頭像）> |gear| **設定 > CryptDrive

  2. 點選 備份 按鈕下載包含所有文件金鑰的檔案。（注意：此與 下載我的 CryptDrive 不同，後者是儲存每份文件的內容）

  3. 在另一套瀏覽器中，以已知密碼註冊新帳號

  4. 登入新帳號後：使用者選單**（右上角頭像）> |gear| **設定 > CryptDrive，再點選 還原 按鈕

如何與其他平台匯入／匯出？#

讓 CryptPad 相容多種文件格式是開發團隊持續努力的目標。在此方面持續改進的同時，以下方法應能協助您與其他常用軟體進行匯入與匯出。

备注

從既有軟體直接複製貼上內容到 CryptPad，是匯入／匯出時可先嘗試的簡單做法。請注意，以下匯入／匯出方式可顯著改善結果。

可將 檔案 上傳至 CryptPad 以安全儲存與分享，但上傳後不會自動變成可編輯的 CryptPad 文件。若要編輯，您需要：

  • 在已上傳的檔案上 按右鍵 > 在編輯器中開啟，或…

  • 建立空白文件，並在對應的 CryptPad 編輯器中使用 檔案 > 匯入 功能（如下所述）

警告

  • 目前尚不支援在 macOS、iPadOS 與 iOS 上使用的 Safari 網頁瀏覽器

  • CSV 支援目前有問題，.csv 匯入／匯出暫時停用

  • OpenDocument 格式 <https://en.wikipedia.org/wiki/OpenDocument>`_（`.odt``、.odp 與 .ods）的匯入／匯出目前為實驗功能，可能出錯

若遇到任何問題，請先查看 常見問題與排除。若依說明仍無法正常使用，請透過本站的 技術支援 客服聯絡管理員，並可使用 分享連結 功能提供範例文件連結。

檔案選單中看不到匯入／匯出#

試算表與進階文件處理由 CryptPad 整合 OnlyOffice 提供，因此同一畫面上會有兩組工具列、各自有檔案選單。尋找匯入／匯出時請記得兩個選單都看一下。

文件應用程式的匯入／匯出#

文件 支援的格式為 Microsoft Word .docx 與 OpenDocument .odt，可從 Google 文件、LibreOffice Writer 等常用軟體匯出：

  1. 在您現有軟體中將文件匯出為 .docx 或 .odt

  2. 將檔案儲存到您的電腦

  3. 開啟新的 文件 檔案（或既有檔案以取代內容）

  4. 檔案 > 匯入，並選擇您的檔案

若要匯出，請使用 檔案 > 匯出 並選擇格式：

  • 若要在 Microsoft Word 或 Google 文件中使用，請選 .docx

  • 若要在 LibreOffice Writer 中使用，請選 .odt

  • 若匯出後不需再編輯（如信件、報告等），請選 .pdf

  • 若要備份或與其他 CryptPad 站台的使用者分享，請選 .bin

簡報應用程式的匯入／匯出#

簡報 支援的格式為 Microsoft PowerPoint .pptx 與 OpenDocument .odp，可從 Google 簡報、LibreOffice Impress 等常用軟體匯出：

  1. 在您現有軟體中將文件匯出為 .pptx 或 .odp

  2. 將檔案儲存到您的電腦

  3. 開啟新的 簡報 文件（或既有文件以取代內容）

  4. 檔案 > 匯入，並選擇您的檔案

若要匯出，請使用 檔案 > 匯出 並選擇格式：

  • 若要在 Microsoft PowerPoint 或 Google 簡報中使用，請選 .pptx

  • 若要在 LibreOffice Impress 中使用，請選 .odp

  • 若匯出後不需再編輯（如簡報、報告等），請選 .pdf

  • 若要備份或與其他 CryptPad 站台的使用者分享，請選 .bin

試算表應用程式的匯入／匯出#

試算表 支援的格式為 Microsoft Excel .xlsx 與 OpenDocument .ods，可從 Google 試算表、LibreOffice Calc 等常用軟體匯出：

  1. 在您現有軟體中將文件匯出為 .xlsx 或 .ods

  2. 將檔案儲存到您的電腦

  3. 開啟新的 試算表 文件（或既有文件以取代內容）

  4. 檔案 > 匯入，並選擇您的檔案

若要匯出，請使用 檔案 > 匯出 並選擇格式：

  • 若要在 Microsoft Excel 或 Google 試算表中使用，請選 .xlsx

  • 若要在 LibreOffice Calc 中使用，請選 .ods

  • 若匯出後不需再編輯（如簡報、報告等），請選 .pdf

  • 若要備份或與其他 CryptPad 站台的使用者分享，請選 .bin

富文字應用程式的匯入／匯出#

富文字 支援以 HTML 格式匯入／匯出：

  1. 在您現有軟體中將文件匯出為 HTML

  2. 將檔案儲存到您的電腦

  3. 在 CryptPad 上開啟新的 富文字 文件（或既有文件以取代內容）

  4. 檔案 > 匯入，並選擇您的檔案

若要匯出，請使用 檔案 > 匯出，並選擇 .doc 格式。

我建立的文件無法執行某項操作#

CryptPad 部分功能僅限 文件擁有者 使用，包括：

  • 啟用 存取清單

  • 設定密碼

  • 新增或移除其他擁有者

  • 銷毀文件

文件擁有權在 建立時 即已設定；若建立時未指定擁有者，之後無法變更。

開發團隊正考慮在未來取消此區分。目前建議的作法是「擁有」您建立的所有文件，以保留完整控制權，包含銷毀的權限。

可以在手機上使用 CryptPad 嗎？#

CryptPad 設計上盡量支援小螢幕。依裝置效能，應可在手機上使用。2020 年已著手改善響應式介面，若您發現可改進之處，請透過 技術支援 聯絡我們，或到 Github 提交 issue。

會推出專用 App 嗎？#

目前不打算推出專屬行動應用程式，原因如下：

  • 會大幅增加需開發與維護的程式碼，等於要為 iOS 與 Android 各做一套 CryptPad「版本」

  • CryptPad 為開放原始碼，任何人都可架設提供服務。因此行動 App 使用者必須指定要連到哪個 CryptPad 站台，容易造成混淆。此外，各站台可能執行不同版本，端看管理員是否已套用最新更新

為解決上述問題，開發團隊正將 CryptPad 打造成「漸進式網頁應用程式（PWA）」。也就是透過瀏覽器在手機上使用，體驗接近 App，但仍是與桌機相同的軟體。好處是每個 CryptPad 站台都能提供網頁 App，無須由使用者自行選擇要連到哪個站台。

CryptPad 可以與本機檔案系統同步嗎？#

目前 CryptPad 的加密方式尚無法與本機檔案系統同步。此功能常被要求，開發團隊希望未來能提供。

CryptPad 與 OnlyOffice 的關係為何？#

CryptPad 的 文件、簡報 與 試算表 為 OnlyOffice Docs 的整合，但僅涉及用戶端程式，CryptPad 並未使用 OnlyOffice Document Server。CryptPad 用於文件、簡報、試算表等應用的加密協作機制，與上游 OnlyOffice 部分使用的加密系統完全不同。CryptPad 部分檔案格式轉換工具以 OnlyOffice 程式為基礎，但已大幅改寫為在瀏覽器內執行而非伺服器端，因此轉換時無須揭露使用者文件內容。

CryptPad 有多安全？#

CryptPad 旨在保護使用者身分與內容，免於我們與外部威脅的窺探。但安全性並非絕對，需使用者遵循*良好習慣*，且您存取的站台值得信賴。說明與建議請見 我們的部落格。

重點摘要：

  • 假設站台管理員為**善意但好奇**，即雖遵守規則，仍會盡量從可觀察到的資訊取得更多內容。我們維護`CryptPad 公開站台清單 <https://cryptpad.org/instances>`_，並已確認所列站台為最新且設定良好。

  • 通訊管道不可信，可能 主動惡意：外部威脅可竄改、重送或丟棄訊息。這不應影響 CryptPad 的安全性。

  • 您分享文件的對象假設為*善意*，一旦您送出內容，即信任他們不會外洩。但您的*身分*對他們而言仍以弱匿名形式隱藏：他們可看到您的公鑰與顯示名稱。

    • 因此，分享連結*應視為*與密碼同等敏感。建議為檔案再加一層密碼。若有帳號，密碼會儲存在您的CryptDrive（視為安全），存取仍流暢；但外部使用者若取得連結，仍須檔案密碼才能存取。

  • 分享文件時，完整編輯紀錄與協作者都會被看到。若想保密，目前建議作法是先複製一份文件再分享，新副本會有全新的紀錄。

cryptpad.fr 常見問題#

訂閱可以不用信用卡付款嗎？#

我們接受銀行轉帳、PayPal 或其他依需求的方式付款。但因需人工開立發票與處理款項，此選項僅限Duo 方案（含）以上的年繳方案，並需加收 30% 手續費。

訂閱與捐款是否接受加密貨幣？#

我們接受以 Bitcoin 付款，需依前題所述負擔 人工處理手續費。此外，我們為法國註冊公司，依法須取得姓名與地址以開立發票，以及用於訂閱聯絡的電子郵件。

能否提供資料處理協議（DPA）？#

DPA 為我們 組織方案 的一項功能，該頁面可預覽範例 DPA。
