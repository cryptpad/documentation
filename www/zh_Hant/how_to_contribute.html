如何參與貢獻#

參與貢獻 CryptPad 的方式有很多種，其中不少完全不需要會寫程式。若您想討論本文所列的項目，或其它貢獻方式，歡迎 與開發團隊聯絡。

幫忙宣傳#

幫助 CryptPad 最簡單的方式，就是讓更多人知道這個專案。作為開放原始碼專案，CryptPad 能用在行銷的預算非常有限，我們仰賴社群幫忙推廣服務，例如：

  • 自己使用 CryptPad，並向親友、同事示範，說明隱私為何重要。

  • 在社群媒體上發文介紹 CryptPad。

  • 追蹤並轉發我們在 部落格 或 Mastodon 帳號 的訊息。

  • 轉發 CryptPad 群眾募資 的資訊。

  • 在研討會或聚會中介紹 CryptPad，或邀請團隊前往分享。

  • 更新任何提到 CryptPad 的公開目錄、為專案按讚，並留言描述您的使用經驗。

過往簡報範例請參閱 CryptPad Peertube 頻道，內有 英文 與 法文 的簡報播放清單。

以下為有提到本專案的部分公開目錄：

  • Privacy Guides

  • AlternativeTo

  • Slant

  • Product Hunt

  • SourceForge

  • Slashdot

  • Stackshare

回報錯誤#

若您在使用 CryptPad 時遇到問題，回報有助於讓服務對大家都更好。回報時請盡量提供：問題發生時的情境、您預期的結果，以及實際發生的情況。這些細節能幫助團隊重現錯誤，是修復的第一步。

回報錯誤或問題有兩種方式：

  • CryptPad 內建的 支援單系統，可傳訊息給站台管理員。這些訊息與 CryptPad 上其他內容一樣會加密。

  • 使用 Github 問題追蹤系統 依錯誤回報範本公開提交問題。（需有 Github 帳號才能提交）

貢獻說明文件#

若您對本說明文件有修正、編輯或建議，歡迎貢獻並幫助大家把服務做得更好。請將您的修改建議寄到 論壇，或使用 GitHub 的 pull request 提交。

翻譯 CryptPad#

CryptPad 團隊負責英文與法文，其餘語言由社群提供。翻譯 CryptPad，以及／或在平台更新時維持翻譯最新，是讓更多人能使用的重要工作。

若要翻譯 CryptPad 軟體本身，請參閱 翻譯指南。

若要翻譯本說明文件，請至 Weblate 上的專案參與。若要新增語言，請 與開發團隊聯絡。

社群翻譯計畫#

CryptPad 的翻譯由社群志工協力完成。我們無法提供翻譯工作的金錢報酬，但會以感謝之意在 CryptPad.fr 提供免費進階方案（更多儲存空間與優先支援）。

條款#

翻譯者承諾

  • 在我們的 Weblate 站台 註冊帳號，並以此帳號進行所有翻譯工作

  • 將某語言翻譯至接近或達到 100%，並持續維持

  • 隨 CryptPad 約每年四次的新版釋出維持翻譯更新（工作量依每次釋出的功能多寡而定）

CryptPad 開發團隊承諾

  • 在翻譯者履行承諾的前提下，為每位翻譯者在 CryptPad.fr 啟用免費的 個人方案

  • 在 CryptPad 翻譯 Matrix 頻道 提供指引與支援

  • 代管並維護 Weblate 站台，包含所有工具、術語表等

此計畫目前僅適用於個人翻譯者；若您以團體方式參與翻譯，請與開發團隊聯絡。

貢獻程式碼#

CryptPad 以 JavaScript 撰寫，我們在 Github 接受 pull request。請注意安全層與應用層是分開的，因此即使不熟悉密碼學也能貢獻 CryptPad。貢獻項目依難度大致包括：

  • 修復 問題追蹤系統 上的錯誤。

  • 新增功能。

  • 開發新應用程式，或將既有應用整合進 CryptPad 的加密即時協作環境。

更多資訊與 貢獻程式碼 的細節，請參閱 開發者指南。

金援贊助#

協助 CryptPad 財務永續的方式：

  • 在 Open Collective 進行單次或定期捐款。

  • 訂閱 cryptpad.fr。

  • 若為較大型組織，想贊助某項功能或討論自架站台的支援合約，請 與團隊聯絡。

备注

給站台擁有者的說明：cryptpad.fr 過去曾為自架站台的訂閱提供營收分潤機制，目前此機制已停止。若您是站台擁有者且對這類機制有興趣，我們仍樂意聆聽您的想法，未來也可能考慮與大型站台擁有者恢復此類營收分潤模式。
