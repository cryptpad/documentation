簡報¶

CryptPad 的簡報應用程式整合了 CodeMirror。

工具列¶

工具：顯示或隱藏文字編輯器工具列。

插入：在文件中加入圖片。可從雲端硬碟選擇或上傳。 已登入使用者

主題：設定編輯器色彩，詳見 下方。

預覽：顯示或隱藏簡報預覽窗格。

放映：以全螢幕模式啟動簡報。

使用 Markdown 撰寫簡報¶

CryptPad 簡報以 Markdown 撰寫，這是一種輕量語法，可提供基本排版並保持易讀。

Markdown 語法說明

簡報應用程式在基本 Markdown 之外，主要多了用 --- 分隔符來區分不同投影片。

主題¶

選項：

  • 版面配置：切換投影片編號、日期、標題與轉場效果。

  • 背景圖片：會顯示在每張投影片上。

  • 自訂 CSS：貼上 CSS 程式碼以自訂簡報外觀。

文字顏色、 背景顏色：為簡報選擇顏色。

主題：程式碼編輯器窗格所使用的色彩配置。

匯入/匯出¶

檔案 > 匯入。
支援格式：任何純文字檔。
檔案 > 匯出。
支援格式：.md。

圖片¶

基於安全考量，CryptPad 會封鎖以 Markdown 語法嵌入遠端圖片（例如 ![description](https://site.com/image.jpg)）。

已登入使用者

要從 CryptDrive 插入圖片或上傳新圖片，請使用工具列中的 插入 選單。

詳見 遠端內容。

燈箱¶

要以視窗全寬瀏覽文件中的所有圖片與圖表：

  1. 在 Markdown 預覽中**雙擊**圖片或圖表。

  2. 使用方向鍵瀏覽。

  3. 按 或 Esc 關閉燈箱。
